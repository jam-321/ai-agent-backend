# 管理员配置界面结构化改造

- 日期：2026-08-23
- 后端分支：`feature/token-budget-compaction-backend`
- 前端分支：`feature/token-budget-compaction-frontend`

## 背景

原管理员页面全部使用原生 HTML 控件和集中在 `App.vue` 的手写 CSS。Agent 的 Tool、插件和运行参数，以及供应商模型目录，主要依靠管理员直接编辑 JSON，缺少选项约束、联动、字段校验和清晰的信息层级。

## 结构化配置

- 数据库存储格式保持不变，`enabled_tools`、`enabled_plugins`、`magic_params` 和 `models` 继续使用现有 JSON 字段。
- 前端改为结构化控件编辑，并实时展示最终 JSON 预览；JSON 仍可查看和复制，但不再是唯一编辑入口。
- Agent 配置支持：执行类型、Workflow、供应商/模型联动、Temperature、图片历史模式、系统提示词、全部或指定 Tool、插件、AgentLoop 限制、Token 预算、上下文压缩和 Workflow 步骤上限。
- 供应商配置支持：启停、协议、Base URL、Endpoint、API Key 更新，以及可增删的模型目录和模型级图片/Tool 能力。

## 运行时元数据

- 新增 `GET /api/admin/config-options`，从后端 Registry 返回当前实际注册的执行类型、Workflow、协议、Tool 和插件。
- 接口同时返回 YAML 中的 Loop、Budget、Memory、Workflow 全局上限，前端的每 Agent 配置只能在安全范围内调低。
- 选项不在前端硬编码；新增 Tool、插件、协议适配器或 Workflow 后，管理端可以自动获得新选项。

## 前端工程化

- 引入 Element Plus 和官方图标，使用按需自动导入，避免整库进入首屏包。
- 管理模块拆分为 Agent、供应商、用户和审计四个独立页面，并按需懒加载。
- 新增统一主题变量、管理页头部、数据表格、配置抽屉、表单分区和 JSON 预览样式。
- 左侧导航改为浅色工作台样式并加入语义图标；供应商模型编辑器在窄屏下切换为纵向布局。
- 修复无组件路由记录导致导航失效，以及鉴权初始化期间管理员深链接被误重定向的问题。

## 验证

- 后端 Maven 测试 34 项通过。
- 配置元数据接口实测返回 `LOOP/WORKFLOW`、已实现协议、6 个 Tool、2 个插件及 `time_report` Workflow。
- 前端生产构建通过，管理模块成功拆分为独立异步产物，无大包警告。
- 浏览器完成 Agent/供应商列表、编辑抽屉、JSON 预览和 390px 窄屏布局验收；未保存或修改业务配置。
