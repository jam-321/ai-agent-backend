# 2026-08-21：事件插件与 Agent 配方迁移

## 背景

在 `test-project` 试验场验证了“循环 + 事件 + 注册表 + 插件 + ctx”以及 `agent_config` 配方模型。此次将核心架构迁回主工程，同时保留 MVP v1 已验证的异步和可靠性能力。

## 本次变更

- AgentLoop 固定发射 `turn_start`、`lifecycle`、`tool_call`、`tool_result`、`assistant`、`generate` 事件。
- 新增 `Dispatcher`、`EventRegistry`、`Plugin`、`PluginSubscribes` 和 `PluginRegistrar`。
- `NodeTracePlugin` 接管 `conversation_node` 轨迹投影，插件异常由 Dispatcher 隔离。
- `TimeInjectPlugin` 作为普通可选插件，证明插件可以修改本轮模型消息上下文。
- 新增 `agent_config` 表、Repository、初始化配方和 `/api/agents` 接口。
- `conversation` 增加 `agent_key`，聊天请求支持传入 Agent 配方；会话下一轮可以切换配方。
- 配置通过 `AgentConfigSnapshot` 固定到本次 turn，避免异步执行期间读取到不一致配置。
- 工具事件携带独立字段快照，保留主工程多工具并行执行能力。
- 兼容旧数据库：启动迁移会补充 `conversation.agent_key` 和 `agent_config` 表。

## 保留的主工程能力

没有把试验场同步实现直接覆盖到主工程。主工程的 OuterLoop 重试、异步线程池、Redis 会话锁、重启恢复、工具异常回注、短期记忆和 Progress 查询继续保留。
