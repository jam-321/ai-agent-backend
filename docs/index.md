# docs 目录索引（主线 1）

> 本文件是 `ai-agent-backend/docs/` 的导航入口。首次进入主线 1 时，先读它和 `状态.md` 快速建立现状，再按需深入。

## 读取优先级（建议顺序）

1. **`状态.md`** —— 单点真相：当前到哪、最近决策、下一步、关键约束（最前沿，每次会话先读）
2. **`里程碑.md`** —— 阶段成果归档：已达成能力（相对稳定）
3. **`未来规划.md`** —— 方向与阶段（已更新为"Agent 用于游戏场景"；四阶段为远期参考）
4. **`迭代历史/AI-Agent方案设计.md`** —— 早期架构设计（历史参考，四阶段回补时再读）
5. **`environment.md`** —— 本机环境 / Docker / 端口约定
6. **`迭代历史/`** —— 按日期的开发流水，只在需要回顾决策时才读

| 文件 | 是什么 | 何时读 |
