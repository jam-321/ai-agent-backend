## 最近关键决策

- 前后端拆分；后端 Java17 + SpringBoot3.5 + Spring AI + MyBatis-Plus，前端 Vue3 + Vite（初版）。
- 后端按功能模块（agent/auth/conversation/monitoring/workflow/common）。
- AgentLoop 与 Workflow 走统一执行器注册表；事件插件 Dispatcher/Registry。
- 多模型供应商 `model_provider_config`；会话可切换 Agent/模型。
- 图片用 MinIO + `media_asset` 元数据（不存 base64）。
- 上下文压缩检查点在 Turn 成功后才持久化；模型容灾备用模型。
- **主线方向定为「游戏场景」**：Agent 作为"角色灵魂层"，做「游戏 + Agent」（表里双世界 + 关系驱动 agent RPG）。

## 下一步（近期）
